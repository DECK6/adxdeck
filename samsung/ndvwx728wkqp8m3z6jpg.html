1. ChatGPT(코덱스)앱 특징 및 소개

PR 뜻
PR 뜻(Pull Request(풀 리퀘스트)약자)
"제가 이렇게 코드를 수정했는데, 검토하고 본 프로젝트에 반영해 주세요"라고 요청하는 절차
Codex가 격리된 환경에서 코드를 작성·테스트한 뒤 그 결과를 바로 프로젝트에 덮어쓰는 게 아니라, 사용자가 검토할 수 있는 Pull Request 형태로 제출해 준다는 뜻
용어 설명
IDE: Integrated Development Environment(통합 개발 환경)의 약자
코드 편집기, 실행, 디버깅, 파일 관리 등 개발에 필요한 기능을 하나로 모아놓은 프로그램
CLI: Command Line Interface(명령줄 인터페이스)의 약자
마우스로 클릭하는 화면 없이, 터미널 창에 텍스트 명령어를 입력해서 프로그램을 조작하는 방식
CI: Continuous Integration(지속적 통합)의 약자
개발자들이 수정한 코드를 자주 중앙 저장소에 합치고, 합칠 때마다 자동으로 빌드와 테스트를 돌려서 문제를 바로 잡아내는 방식

CD: Continuous Deployment/Delivery(지속적 배포/전달)의 약자
테스트를 통과한 코드를 자동으로 실제 서비스 환경까지 배포하는 방식

"CI/CD 스크립트"는 코드가 저장소에 올라올 때마다 자동으로 테스트하고 배포하는 자동화 파이프라인을 의미합니다.
