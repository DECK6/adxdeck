# 나를 인터뷰하는 온톨로지 · 실습 스킬

질문에 답하다 보면 내 인물·직업·역할·작품·프로젝트·개념이 관계 지도로 정리됩니다. 온톨로지나 JSON을 미리 배울 필요는 없습니다.

1. ZIP을 풀고 `personal-ontology-interview` 폴더 전체를 보관합니다.
2. 파일을 읽을 수 있는 에이전트에게 이 폴더의 `SKILL.md`를 읽힙니다. 스킬 등록 기능을 쓰는 경우에도 폴더 전체를 등록합니다.
3. 아래 요청문으로 시작합니다. 자기소개·경력·프로젝트 메모가 있다면 함께 제공해도 됩니다.

> personal-ontology-interview/SKILL.md를 읽고 나를 인터뷰해줘. 이미 알려준 정보와 내가 제공한 자료부터 확인하고, 한 번에 1~3개씩 물어봐. 나를 둘러싼 사람·직업·역할·작품·프로젝트·개념을 연결하고, 작은 모델이 생기면 내 질문에 써보자. 모르는 관계는 미확인으로 남기고 결과와 다음 질문을 저장해줘.

대화 결과는 `ontology.json`, `ontology.md`, 인터뷰 기록, 활용 질문·답변, 재개 상태로 저장합니다. 파일을 저장할 수 없는 환경에서는 대화에 문서·JSON을 받아 직접 보관할 수 있습니다.

[2주차 실습 페이지](https://dexa.art/ontology/study/week2.html)의 ‘스킬 결과 가져오기’에서 `ontology.json`을 열어 관계와 근거를 볼 수 있습니다. 전체 커리어 예제는 육대근의 참고 사례이며, 이 스킬은 그 예제를 본인 이력으로 복사하지 않습니다.

검사 스크립트는 Bun 또는 Node.js가 있으면 실행할 수 있습니다. Neo4j·Jev·유료 API는 필수가 아닙니다. 스킬 패키지에는 개인 API 키나 특정 컴퓨터 경로가 없습니다.
