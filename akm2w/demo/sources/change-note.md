# 작은 지역 창작 워크숍 변경 공지

## 문서 상태

- 상태: 운영 승인 변경 공지
- 적용 범위: 2026-08-22 워크숍
- 승인일: 2026-08-15
- 우선 적용 항목: 정원과 출입 방식

## 변경 내용

1. 장비 배치 변경으로 참가 정원을 18명에서 12명으로 줄인다.
2. 2층 창작실은 계단으로만 출입할 수 있다.
3. 엘리베이터와 별도 휠체어 출입 동선은 제공되지 않는다.

## 변경하지 않은 내용

일시, 대상, 참가비, 신청 방식, 준비물, 입실·접수 시각, 음식물 규칙은 기존 승인본을 유지한다.

## 여전히 확인되지 않은 항목

이 변경 공지는 주차 가능 여부를 확정하지 않는다.

## 새 Context

참가자가 신청 전에 계단 출입 조건을 알 수 있어야 한다. 접근 조건과 맞지 않는 참가자가 현장에서 처음 알게 되는 일이 없도록 안내문의 일정·장소 구역에 눈에 띄게 적는다.
