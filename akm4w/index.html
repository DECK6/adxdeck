PROBLEM SCENE

1. 도로 위의 문제 장면

내비게이션이 경부고속도로 → 올림픽대로 → 한강대로 → 세종대로 → 종로 경로를 찾았다고 해도, 도로 이름의 나열만으로는 “이 길로 갈 수 있다”는 판단이 끝나지 않습니다. 연결된다가 양방향인지, 보행자도로가 섞였는지, 기록에 없는 연결을 없음으로 볼지 미상으로 둘지 결정해야 합니다.

이번 Week 4의 작은 도로 체계는 이 질문을 배우기 위한 실습 표면입니다. 마크다운 노트, YAML frontmatter, 위키링크, 규칙 노트로 도로·교차로·도로 유형·관계·제약을 표현합니다. 이는 OWL 표준 구현이 아니라 사람이 읽고 수정하기 쉬운 AKM 경량 구현입니다.

핵심 질문은 단순합니다. 어떤 대상을 도로 체계 안에 존재한다고 보고, 어떤 종류와 관계와 규칙으로 판단할 것인가?

ONE SENTENCE

2. 한 문장 정의와 Gruber 뜻풀이

는 특정 영역에서 무엇이 존재한다고 볼지, 그것을 어떤 종류로 나눌지, 어떤 속성과 관계를 가질지, 어떤 규칙이 성립할지 명시한 의미 체계입니다.

도로 사례로 풀면 목적을 먼저 정합니다. 여기서는 연결 경로를 찾고 잘못된 도로 분류를 검출합니다. 그 목적에 필요한 대상은 도로와 교차로이고, 필요한 관계는 연결된다, 진입한다, 우회로다입니다. 필요한 규칙은 자동차전용도로와 보행자도로가 동시에 성립할 수 없다는 배타 조건과 도로에는 제한속도 값이 필요하다는 조건입니다.

파일이 많다는 사실만으로 온톨로지가 되지는 않습니다. 이름, 뜻, 관계, 제약이 함께 명시되어야 같은 이름을 같은 의미로 읽을 수 있습니다.

FROM ONTOLOGY TO REPRESENTATION

3. 철학의 존재론에서 정보 표현으로

철학의 존재론은 “무엇이 존재하는가”를 묻습니다. 컴퓨터과학의 온톨로지는 이 질문을 특정 목적의 정보 표현 문제로 좁혀 가져옵니다. 도로 체계 전체를 완전히 묘사하려는 것이 아니라, 경로 탐색과 오류 검출에 필요한 범위를 정합니다.

따라서 이번 도로 온톨로지는 현실의 모든 도로를 설명하지 않습니다. 목적이 제한속도 정책 비교로 바뀐다면 필요한 속성과 관계가 바뀌고, 목적이 교차로 안전 분석으로 바뀐다면 교차로를 다루는 방식도 바뀝니다.

모델링 선택은 임의가 아니라 질문 의존적입니다. 같은 고속도로도 개별 도로를 분류할 때는 클래스이고, 도로 등급 체계 자체를 연구할 때는 하나의 개체처럼 다룰 수 있습니다.

TERMS IN THE ROAD SYSTEM

4. 온톨로지를 이루는 것들

는 온톨로지가 이름 붙여 다루는 모든 것입니다. 도로, 경부고속도로, 제한속도, 연결된다가 모두 엔티티가 될 수 있습니다.

는 구체적인 대상 하나입니다. 경부고속도로는 인 고속도로에 속합니다. 고속도로는 자동차전용도로의 하위이고, 자동차전용도로는 도로의 하위입니다.

은 값을 붙이거나 다른 대상을 잇는 이름입니다. 제한속도: 100은 데이터 값에 연결하고, 는 도로 개체를 다른 도로 개체에 연결합니다. 관계에는 가 있어 출발 종류와 도착 종류를 제한합니다.

는 값의 개수 조건입니다. 도로에 제한속도 값이 최소 하나 필요하다는 조건과, RDF 부록에서 제한속도 값을 최대 하나만 둔다는 조건은 서로 다릅니다. 최소 하나와 최대 하나를 함께 두어야 정확히 하나가 됩니다.

는 모델이 참이라고 선언하는 문장이고, 은 허용되는 값·개수·조합을 제한하는 조건입니다. 는 같은 개체가 두 클래스에 동시에 속할 수 없다는 조건입니다. 는 이미 적힌 사실과 공리에서 따라오는 결론을 계산합니다.

TRIPLE

5. RDF 트리플은 왜 세 자리인가

은 하나의 사실을 주어·술어·목적어 세 자리로 표현합니다. 경부고속도로 — 연결된다 → 올림픽대로에서 주어는 경부고속도로, 술어는 연결된다, 목적어는 올림픽대로입니다.

세 자리로 나누면 같은 주어에 제한속도 → 100, 차로수 → 4를 더하고, 같은 술어로 여러 도로를 질의할 수 있습니다. 목적어가 다른 도로이면 다시 그 도로를 주어로 삼아 그래프를 이어갈 수 있고, 목적어가 숫자이면 필터링할 수 있습니다.

이번 마크다운의 한 줄이 자동으로 표준 RDF가 되는 것은 아닙니다. 교육적으로 트리플처럼 읽을 수 있게 만든 경량 표현입니다.

RDF / RDFS / OWL

6. OWL 2가 더하는 것

은 경쟁 파일 형식이 아니라 관련 표준 층입니다. RDF는 트리플 그래프 모델이고, RDFS는 클래스·하위 클래스·도메인·레인지 같은 기본 스키마 어휘를 더하며, OWL은 배타·동등성·카디널리티·속성 특성 같은 풍부한 공리와 형식 의미를 제공합니다.

도로 모델에서 경부고속도로 연결된다 올림픽대로는 RDF식 사실이고, 고속도로 rdfs:subClassOf 자동차전용도로는 RDFS 계층이며, 자동차전용도로 owl:disjointWith 보행자도로와 제한속도 최대 카디널리티는 OWL 표현력이 필요한 부분입니다.

는 같은 그래프를 파일로 적는 문법입니다. Turtle, RDF/XML, JSON-LD는 같은 RDF 그래프를 다르게 적을 수 있습니다.

OWA / CWA / NO UNA

7. 열린 세계와 고유이름 가정 없음

은 기록에 없는 사실을 어떻게 다룰지의 차이입니다. OWA는 노트에 없는 연결을 곧 거짓으로 보지 않고 미상으로 둡니다. CWA는 완전하다고 정한 기록 범위에 없으면 거짓으로 다루는 운영 방식입니다.

이번 Python 검사기는 주어진 17개 파일을 닫힌 검사 집합처럼 다룹니다. 반대로 OWL 부록의 의미는 부재가 미상일 수 있는 열린 세계 쪽에 가깝습니다. OWA는 “없는 사실도 참”이 아니라 “미상과 거짓을 구분”한다는 뜻입니다.

도 중요합니다. OWL에서는 서로 다른 이름이 자동으로 서로 다른 개체를 가리킨다고 가정하지 않습니다. 경부고속도로와 경부 고속도로가 같은 도로인지 다른 도로인지는 이름만으로 확정하지 않습니다.

FIVE CONCEPTS

8. 다섯 개념을 한 번에 구분하기

텍소노미, 스키마, 데이터베이스, 지식그래프, 온톨로지는 서로 겹칠 수 있지만 같은 말은 아닙니다. 아래 비교 도구는 “도로 체계에서 지금 필요한 보장이 무엇인가”로 선택하게 만듭니다.

작은 분류 질문에는 텍소노미가 충분할 수 있고, 입력 칸을 통일하려면 스키마가 먼저입니다. 실제 레코드 운영은 데이터베이스의 일입니다. 관계 탐색은 지식그래프가 강하고, 관계의 뜻·배타·추론을 공유해야 할 때 온톨로지가 필요합니다.

STANDARD VS LIGHTWEIGHT

9. 표준 방식과 AKM 경량 방식

표준 RDF/OWL 방식은 전역 IRI, W3C 형식 의미, 표준 도구와의 교환 가능성, OWL 추론기의 힘을 얻습니다. 대신 문법과 의미론, 도구 학습 비용이 있습니다.

AKM 경량 방식은 파일명·위키링크·frontmatter·규칙 노트로 사람이 바로 읽고 수정할 수 있게 합니다. 시작 비용은 낮지만 표준 상호운용성과 형식 추론기는 자동으로 얻지 못합니다.

중요한 것은 “RDF를 쓰면 온톨로지이고 마크다운이면 아니다”가 아닙니다. 반대로 마크다운 키 몇 개가 RDF/OWL과 같은 능력을 갖는 것도 아닙니다. 표현 형식과 의미 보장을 분리해 말해야 합니다.

ITERATION

10. 온톨로지를 만드는 반복 절차

온톨로지는 한 번에 완성하는 정답지가 아니라 질문에 맞춰 반복해서 다듬는 의미 체계입니다. 먼저 범위와 질문을 정합니다. 이번 질문은 “경부고속도로에서 어떤 도로까지 도달 가능한가?”와 “배타 클래스 위반을 찾을 수 있는가?”입니다.

  1. 이미 쓰는 도로 유형과 관계 이름을 검토합니다.
  2. 도로, 교차로, 연결, 제한속도처럼 질문에 필요한 용어만 고릅니다.
  3. 클래스와 계층을 만듭니다.
  4. 속성과 관계의 방향, 도메인, 레인지를 문장으로 읽습니다.
  5. 값 유형, 카디널리티, 배타 조건을 필요한 만큼만 둡니다.
  6. 개체를 넣고 실제 질문을 다시 실행합니다.

유일한 정답이 없다는 말은 기준이 없다는 뜻이 아닙니다. 질문에 답하는가, 관계가 명확한가, 유지 가능한가, 잘못된 기록을 찾는가가 비교 기준입니다.

KG + ONTOLOGY

11. 지식그래프와 온톨로지의 관계

는 실제 도로·교차로·유형 노트가 노드로, 관계가 엣지로 이어진 데이터 망입니다. 온톨로지는 그 그래프가 쓰는 상위 용어의 의미, 클래스 계층, 관계 특성과 규칙을 정의하는 층이 될 수 있습니다.

road-notes/에서는 개체 노트와 위키링크가 데이터 그래프를 이루고, 타입 노트와 규칙 노트가 의미와 제약을 보탭니다. 노드와 엣지가 보인다고 관계의 뜻, 데이터의 참, 형식 추론이 자동 보장되는 것은 아닙니다.

따라서 지식그래프와 온톨로지는 협력할 수 있지만 등치하지 않습니다. 데이터 망과 의미 규칙을 구분할수록 LLM에게 줄 근거도 더 정확해집니다.

#!/usr/bin/env python3
"""AKM 경량 도로 온톨로지 노트와 관계를 검사한다."""

from __future__ import annotations

import ast
import re
import sys
from collections import deque
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Iterable, Sequence


DEFAULT_NOTES_DIR = Path(__file__).with_name("road-notes")
RELATION_FIELDS = ("연결된다", "진입한다", "우회로다")
DOMAIN_LINK_FIELDS = (
    "type",
    "parentType",
    "배타",
    "연결된다",
    "진입한다",
    "우회로다",
)
WIKILINK_PATTERN = re.compile(r"^\[\[([^\]|#]+)(?:#[^\]|]+)?(?:\|[^\]]+)?\]\]$")


class OntologyError(Exception):
    """입력 파일 또는 frontmatter가 계약에 맞지 않을 때 발생한다."""


@dataclass(frozen=True)
class Note:
    name: str
    path: Path
    metadata: dict[str, Any]


@dataclass(frozen=True)
class Report:
    type_notes: dict[str, Note]
    individual_notes: dict[str, Note]
    rule_notes: dict[str, Note]
    relationship_count: int
    reachable: list[str]
    high_speed_roads: list[tuple[str, int]]
    disjoint_violations: list[tuple[str, str, str]]
    domain_violations: list[str]
    missing_required_properties: list[str]
    asymmetric_connections: list[str]
    broken_links: list[str]


def parse_value(raw_value: str, *, path: Path, line_number: int) -> Any:
    """이 자료가 쓰는 YAML 스칼라와 인라인 배열만 파싱한다."""
    value = raw_value.strip()
    lowered = value.lower()
    if lowered == "true":
        return True
    if lowered == "false":
        return False
    if re.fullmatch(r"[-+]?\d+", value):
        return int(value)
    if value.startswith(("\"", "'", "[")):
        try:
            parsed = ast.literal_eval(value)
        except (SyntaxError, ValueError) as exc:
            raise OntologyError(
                f"{path}:{line_number}: 따옴표 문자열 또는 인라인 배열을 파싱할 수 없습니다"
            ) from exc
        if isinstance(parsed, list) and not all(
            isinstance(item, (str, int, bool)) for item in parsed
        ):
            raise OntologyError(f"{path}:{line_number}: 지원하지 않는 배열 값입니다")
        if not isinstance(parsed, (str, int, bool, list)):
            raise OntologyError(f"{path}:{line_number}: 지원하지 않는 값입니다")
        return parsed
    if not value:
        raise OntologyError(f"{path}:{line_number}: 빈 값은 지원하지 않습니다")
    return value


def parse_frontmatter(path: Path) -> dict[str, Any]:
    """Markdown 시작 부분의 --- frontmatter를 직접 추출한다."""
    try:
        lines = path.read_text(encoding="utf-8").splitlines()
    except OSError as exc:
        raise OntologyError(f"파일을 읽을 수 없습니다: {path}: {exc}") from exc

    if not lines or lines[0].strip() != "---":
        raise OntologyError(f"frontmatter 시작 구분자가 없습니다: {path}")
    try:
        closing_index = next(
            index for index, line in enumerate(lines[1:], start=1) if line.strip() == "---"
        )
    except StopIteration as exc:
        raise OntologyError(f"frontmatter 종료 구분자가 없습니다: {path}") from exc

    metadata: dict[str, Any] = {}
    for index, line in enumerate(lines[1:closing_index], start=2):
        if not line.strip() or line.lstrip().startswith("#"):
            continue
        if line.startswith((" ", "\t")) or ":" not in line:
            raise OntologyError(
                f"{path}:{index}: 최상위 key: value 또는 인라인 배열만 지원합니다"
            )
        key, raw_value = line.split(":", 1)
        key = key.strip()
        if not key or key in metadata:
            raise OntologyError(f"{path}:{index}: 비어 있거나 중복된 키입니다: {key!r}")
        metadata[key] = parse_value(raw_value, path=path, line_number=index)
    return metadata


def load_notes(notes_dir: Path) -> dict[str, Note]:
    """road-notes 아래 모든 Markdown를 파일명 기준으로 불러온다."""
    if not notes_dir.is_dir():
        raise OntologyError(f"노트 디렉터리가 없습니다: {notes_dir}")
    paths = sorted(notes_dir.rglob("*.md"))
    if not paths:
        raise OntologyError(f"Markdown 노트가 없습니다: {notes_dir}")

    notes: dict[str, Note] = {}
    for path in paths:
        name = path.stem
        if name in notes:
            raise OntologyError(f"중복된 노트 이름입니다: {name}")
        notes[name] = Note(name=name, path=path, metadata=parse_frontmatter(path))
    return notes


def as_items(value: Any) -> list[Any]:
    if isinstance(value, list):
        return value
    return [value]


def wikilink_target(value: Any) -> str | None:
    if not isinstance(value, str):
        return None
    match = WIKILINK_PATTERN.fullmatch(value)
    return match.group(1) if match else None


def linked_targets(note: Note, field: str) -> list[str]:
    return [
        target
        for item in as_items(note.metadata.get(field, []))
        if (target := wikilink_target(item)) is not None
    ]


def direct_types(note: Note) -> list[str]:
    return [
        target
        for item in as_items(note.metadata.get("type", []))
        if (target := wikilink_target(item)) is not None
    ]


def type_closure(type_names: Iterable[str], parents: dict[str, str]) -> set[str]:
    closure: set[str] = set()
    pending = list(type_names)
    while pending:
        current = pending.pop()
        if current in closure:
            continue
        closure.add(current)
        if parent := parents.get(current):
            pending.append(parent)
    return closure


def analyze(notes: dict[str, Note]) -> Report:
    """그래프 질의와 네 가지 일관성 검사를 수행한다."""
    type_notes = {
        name: note for name, note in notes.items() if note.metadata.get("type") == "도로타입"
    }
    rule_notes = {
        name: note for name, note in notes.items() if note.metadata.get("type") == "규칙"
    }
    individual_notes = {
        name: note
        for name, note in notes.items()
        if name not in type_notes and name not in rule_notes
    }

    parents = {
        name: targets[0]
        for name, note in type_notes.items()
        if (targets := linked_targets(note, "parentType"))
    }
    individual_types = {
        name: type_closure(direct_types(note), parents)
        for name, note in individual_notes.items()
    }

    relationship_count = sum(
        len(linked_targets(note, field))
        for note in individual_notes.values()
        for field in RELATION_FIELDS
    )

    adjacency = {
        name: linked_targets(note, "연결된다")
        for name, note in individual_notes.items()
    }
    reachable: list[str] = []
    visited = {"경부고속도로"}
    queue = deque(adjacency.get("경부고속도로", []))
    while queue:
        current = queue.popleft()
        if current in visited:
            continue
        visited.add(current)
        reachable.append(current)
        queue.extend(adjacency.get(current, []))

    high_speed_roads = sorted(
        (
            (name, speed)
            for name, note in individual_notes.items()
            if isinstance((speed := note.metadata.get("제한속도")), int) and speed >= 80
        ),
        key=lambda item: (-item[1], item[0]),
    )

    disjoint_pairs: set[tuple[str, str]] = set()
    for left, note in type_notes.items():
        for right in linked_targets(note, "배타"):
            disjoint_pairs.add((left, right))
    disjoint_violations = sorted(
        (name, left, right)
        for name, types in individual_types.items()
        for left, right in disjoint_pairs
        if left in types and right in types
    )

    road_individuals = {
        name for name, types in individual_types.items() if "도로" in types
    }
    domain_violations: list[str] = []
    for name, note in individual_notes.items():
        for field in ("제한속도", "차로수"):
            if field in note.metadata and name not in road_individuals:
                domain_violations.append(f"{name}.{field}: 도로 개체가 아님")
        for field in RELATION_FIELDS:
            targets = linked_targets(note, field)
            if targets and name not in road_individuals:
                domain_violations.append(f"{name}.{field}: 출발 개체가 도로가 아님")
            for target in targets:
                if target in individual_notes and target not in road_individuals:
                    domain_violations.append(f"{name}.{field} → {target}: 대상이 도로가 아님")

    missing_required_properties = sorted(
        name
        for name in road_individuals
        if not isinstance(individual_notes[name].metadata.get("제한속도"), int)
    )

    asymmetric_connections = sorted(
        f"{source} → {target}"
        for source, targets in adjacency.items()
        for target in targets
        if target in individual_notes and source not in adjacency.get(target, [])
    )

    broken_links = sorted(
        f"{note.name}.{field} → {target}"
        for note in notes.values()
        for field in DOMAIN_LINK_FIELDS
        for item in as_items(note.metadata.get(field, []))
        if (target := wikilink_target(item)) is not None and target not in notes
    )

    return Report(
        type_notes=type_notes,
        individual_notes=individual_notes,
        rule_notes=rule_notes,
        relationship_count=relationship_count,
        reachable=reachable,
        high_speed_roads=high_speed_roads,
        disjoint_violations=disjoint_violations,
        domain_violations=sorted(domain_violations),
        missing_required_properties=missing_required_properties,
        asymmetric_connections=asymmetric_connections,
        broken_links=broken_links,
    )


def print_items(items: Sequence[str], empty_message: str) -> None:
    if items:
        for item in items:
            print(f"  - {item}")
    else:
        print(f"  - {empty_message}")


def print_type_tree(type_notes: dict[str, Note]) -> None:
    children: dict[str | None, list[str]] = {}
    for name, note in type_notes.items():
        parents = linked_targets(note, "parentType")
        parent = parents[0] if parents else None
        children.setdefault(parent, []).append(name)

    preferred_roots = [name for name in ("도로", "교차로") if name in type_notes]
    other_roots = sorted(set(children.get(None, [])) - set(preferred_roots))

    def walk(name: str, depth: int, visited: set[str]) -> None:
        print(f"  {'  ' * depth}- {name}")
        if name in visited:
            print(f"  {'  ' * (depth + 1)}- (순환 참조)")
            return
        next_visited = visited | {name}
        for child in sorted(children.get(name, [])):
            walk(child, depth + 1, next_visited)

    for root in preferred_roots + other_roots:
        walk(root, 0, set())


def print_report(notes: dict[str, Note], report: Report) -> None:
    """정확히 일곱 개의 번호 구역으로 검사 결과를 출력한다."""
    print("1) 노트/타입/개체/관계 요약")
    print(f"  - 전체 노트: {len(notes)}개")
    print(f"  - 타입: {len(report.type_notes)}개")
    print(f"  - 개체: {len(report.individual_notes)}개")
    print(f"  - 규칙: {len(report.rule_notes)}개")
    print(
        f"  - 방향성 링크 항목 합계: {report.relationship_count}개 "
        "(개체 노트의 연결된다·진입한다·우회로다 기록 기준)"
    )

    print("\n2) 타입 계층 트리")
    print_type_tree(report.type_notes)

    print("\n3) 경부고속도로 연결된다 BFS 도달 목록")
    print_items(report.reachable, "도달 가능한 도로 없음")

    print("\n4) 제한속도 80 이상 도로")
    print_items(
        [f"{name}: {speed}" for name, speed in report.high_speed_roads],
        "해당 도로 없음",
    )

    print("\n5) 규칙 검사")
    print(f"  - 배타 위반: {len(report.disjoint_violations)}건")
    print_items(
        [
            f"{name}: {left} / {right} 동시 소속"
            for name, left, right in report.disjoint_violations
        ],
        "없음",
    )
    print(f"  - 도메인 위반: {len(report.domain_violations)}건")
    print_items(report.domain_violations, "없음")
    print(f"  - 필수 속성 위반: {len(report.missing_required_properties)}건")
    print_items(report.missing_required_properties, "없음")

    print("\n6) 연결된다 양방향 일관성")
    print(f"  - 양방향 불일치: {len(report.asymmetric_connections)}건")
    print_items(report.asymmetric_connections, "없음")

    print("\n7) 깨진 위키링크")
    print(f"  - 깨진 위키링크: {len(report.broken_links)}건")
    print_items(report.broken_links, "없음")


def main(argv: Sequence[str] | None = None) -> int:
    arguments = list(sys.argv[1:] if argv is None else argv)
    if len(arguments) > 1:
        print("사용법: check_ontology.py [road-notes 경로]", file=sys.stderr)
        return 2
    notes_dir = Path(arguments[0]).resolve() if arguments else DEFAULT_NOTES_DIR
    try:
        notes = load_notes(notes_dir)
        report = analyze(notes)
        print_report(notes, report)
    except (OntologyError, OSError) as exc:
        print(f"검사 오류: {exc}", file=sys.stderr)
        return 1
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

#!/usr/bin/env python3
"""작은 도로 온톨로지를 파싱하고 강의용 SPARQL 질의를 검증한다."""

from __future__ import annotations

import sys
from pathlib import Path
from typing import Sequence

from rdflib import Graph, URIRef
from rdflib.query import ResultRow
from rdflib.term import Identifier


TTL_PATH = Path(__file__).with_name("road.ttl")

PREFIXES = """
PREFIX : <http://example.org/road#>
PREFIX owl: <http://www.w3.org/2002/07/owl#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
"""

TRIPLE_COUNT_QUERY = """
SELECT (COUNT(*) AS ?count)
WHERE { ?subject ?predicate ?object }
"""

CLASS_HIERARCHY_QUERY = PREFIXES + """
SELECT ?class ?classLabel ?parent ?parentLabel
WHERE {
  ?class a owl:Class ;
         rdfs:label ?classLabel .
  FILTER(lang(?classLabel) = "ko")
  OPTIONAL {
    ?class rdfs:subClassOf ?parent .
    ?parent a owl:Class ;
            rdfs:label ?parentLabel .
    FILTER(lang(?parentLabel) = "ko")
  }
}
ORDER BY ?classLabel
"""

REACHABLE_ROADS_QUERY = PREFIXES + """
SELECT DISTINCT ?road ?label
WHERE {
  :경부고속도로 :연결된다+ ?road .
  ?road rdfs:label ?label .
  FILTER(lang(?label) = "ko")
}
ORDER BY ?label
"""

HIGH_SPEED_ROADS_QUERY = PREFIXES + """
SELECT ?road ?label ?speed
WHERE {
  ?road :제한속도 ?speed ;
        rdfs:label ?label .
  FILTER(lang(?label) = "ko" && ?speed >= 80)
}
ORDER BY DESC(?speed) ?label
"""

DISJOINT_VIOLATIONS_QUERY = PREFIXES + """
SELECT DISTINCT ?individual ?individualLabel ?leftLabel ?rightLabel
WHERE {
  ?left owl:disjointWith ?right .
  ?individual a ?left, ?right ;
              rdfs:label ?individualLabel .
  ?left rdfs:label ?leftLabel .
  ?right rdfs:label ?rightLabel .
  FILTER(
    lang(?individualLabel) = "ko" &&
    lang(?leftLabel) = "ko" &&
    lang(?rightLabel) = "ko"
  )
}
ORDER BY ?individualLabel
"""


def text(value: Identifier | None) -> str:
    """질의 값을 사람이 읽기 좋은 문자열로 바꾼다."""
    if value is None:
        return "(상위 클래스 없음)"
    if isinstance(value, URIRef):
        return value.split("#")[-1]
    return str(value)


def print_section(number: int, title: str, rows: Sequence[str]) -> None:
    """질의 결과 한 구역을 출력하고 빈 결과를 실패로 처리한다."""
    if not rows:
        raise AssertionError(f"[{number}] {title}: 결과가 비어 있습니다")

    print(f"\n[{number}] {title}")
    print(f"결과 수: {len(rows)}")
    for row in rows:
        print(f"- {row}")


def query_rows(graph: Graph, query: str) -> list[ResultRow]:
    """SPARQL SELECT 결과를 순서대로 반환한다."""
    return [row for row in graph.query(query) if isinstance(row, ResultRow)]


def verify() -> None:
    """온톨로지를 파싱하고 다섯 검증 결과를 출력한다."""
    graph = Graph()
    graph.parse(TTL_PATH, format="turtle")

    print("도로 온톨로지 실행 검증")
    print(f"파일: {TTL_PATH}")
    print("파싱: 성공")

    count_rows = [
        f"트리플 총 개수: {text(row[0])}"
        for row in query_rows(graph, TRIPLE_COUNT_QUERY)
    ]
    print_section(1, "트리플 총 개수 (SPARQL)", count_rows)

    hierarchy_rows = []
    for row in query_rows(graph, CLASS_HIERARCHY_QUERY):
        child = text(row.classLabel)
        parent = text(row.parentLabel)
        hierarchy_rows.append(f"{child} → {parent}")
    print_section(2, "클래스 목록과 계층 (SPARQL)", hierarchy_rows)

    reachable_rows = [
        f"경부고속도로 → {text(row.label)}"
        for row in query_rows(graph, REACHABLE_ROADS_QUERY)
    ]
    print_section(
        3,
        "경부고속도로에서 도달 가능한 도로 (전이 경로 :연결된다+)",
        reachable_rows,
    )

    speed_rows = [
        f"{text(row.label)}: 제한속도 {text(row.speed)}"
        for row in query_rows(graph, HIGH_SPEED_ROADS_QUERY)
    ]
    print_section(4, "제한속도 80 이상인 도로 (FILTER)", speed_rows)

    violation_rows = [
        (
            f"{text(row.individualLabel)}: "
            f"{text(row.leftLabel)} / {text(row.rightLabel)} 동시 소속"
        )
        for row in query_rows(graph, DISJOINT_VIOLATIONS_QUERY)
    ]
    print_section(5, "disjoint 제약 위반 후보", violation_rows)

    print("\n검증 결과: 성공 (5개 결과가 모두 비어 있지 않음)")


def main() -> int:
    try:
        verify()
    except Exception as exc:
        print(f"검증 결과: 실패 — {exc}", file=sys.stderr)
        return 1
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
