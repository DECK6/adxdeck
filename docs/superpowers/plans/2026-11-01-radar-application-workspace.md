Architecture critique: static browser storage alone cannot reach scheduled producers. An isolated Worker/D1 avoids changing NARA and uses per-item revisions rather than a race-prone shared KV map. Domain-derived signing key means the Worker never receives the encryption key or original password. No new product dependencies; Wrangler is a development/deployment tool. Keep source data encrypted; state API responses are authenticated and no-store. Missing backend means read-only state UI, not false success. The ledger is a user correction layer; producer evidence and final result status stay attributable.
