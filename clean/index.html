Codex 실습 환경을
안전하게 정리하세요.

실행 전에 정리 대상을 먼저 보여 주고, 승인한 파일만 Windows 휴지통으로 이동합니다. 남은 Codex 유령 프로세스는 PID 확인 후 강제 종료할 수 있습니다. Chrome·Edge도 표시된 PID를 확인하고 별도 승인하면 강제 종료합니다. 강제 종료 시 작성 중인 폼·탭·다운로드가 끊길 수 있습니다. 다운로드 폴더 안의 모든 파일과 폴더도 정리 대상입니다. Chrome·Edge 기록도 정리하되 쿠키·비밀번호·북마크는 보존합니다.

↓ Windows 배치파일 다운로드 windows-codex-cleanup.bat · 24.7 KB

다운로드 후 더블클릭하고, 반드시 1번 미리보기부터 확인하세요.

01

세 단계로 실행

처음에는 반드시 미리보기로 시작하세요.

  1. 01

    앱 완전 종료

    Codex·ChatGPT·Chrome·Edge를 정상 종료합니다. 남은 프로세스는 PID를 확인한 뒤 그룹별 승인으로 강제 종료할 수 있습니다.

  2. 02

    미리보기 선택

    배치파일을 실행하고 1번을 선택해 이동될 경로를 확인합니다.

  3. 03

    정리 실행

    다시 실행해 2번을 선택하고 CLEANUP을 입력합니다.

AUTOMATED

자동으로 정리하는 항목

  • plugins와 auth.json을 제외한 Codex 로컬 상태
  • 사용자가 별도 승인한 Codex·ChatGPT 유령 프로세스 강제 종료
  • 사용자가 별도 승인한 Chrome·Edge 프로세스 강제 종료
  • 바탕화면·다운로드·문서의 이름이 정확히 일치하는 실습 폴더
  • 바탕화면의 에이전트 클래스, 문서의 ChatGPT·Codex
  • 다운로드 폴더 안의 모든 파일과 폴더(실행 중인 배치파일은 창이 닫힌 뒤 휴지통으로 이동)
  • 사용자가 승인한 스크린샷 및 추가 파일
  • 모든 Chrome·Edge 프로필의 방문·다운로드 기록
MANUAL CHECK

마지막에 직접 확인할 항목

  • Codex 워크스페이스 재설정 및 프레젠테이션 플러그인
  • 예약 작업·프로젝트·채팅이 남아 있지 않은지 확인
  • Windows 휴지통 최종 확인
