# GPTers 24기 2주차 · 나를 둘러싼 세계

작성·개정: 2026-10-06 · 수업: 2026-10-07

육대근의 실제 커리어·작품·프로젝트를 연결한 실습 예제입니다. 주변 인물·기관은 익명화했습니다. 커리어 DB 95개 기록과 후속 프로젝트 기록 14개를 연결하며 구상·증빙 보강·과거 시점을 보존합니다.

1. https://dexa.art/ontology/study/week2.html 에서 4단계 커리어 전체를 펼칩니다.
2. sample.json은 JSON 가져오기로 편집할 수 있습니다. ontology.md는 종류·관계·근거를 포함합니다.
3. agent-prompt.txt를 자기 원문과 함께 에이전트에게 전달하고 실제 답변과 수정 사항을 기록합니다.
4. 다른 사람의 사례를 자기 이력으로 사용하지 말고 자기 자료로 대상을 바꿉니다.

웹 전체 오프라인 ZIP을 사용할 때는 압축을 푼 폴더에서 `python3 -m http.server 8000`을 실행하고 http://localhost:8000/week2.html 을 엽니다.
