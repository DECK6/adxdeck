# 3주차 · 내 AKM에 적용하고 실제 질문

실습 40–60분 — 시간은 권장값입니다.

1. 내 작업 ZIP을 내려받고 기존 실습 AKM에서 원본·정리 노트·모델을 확인합니다.
2. 모델을 문서의 ID·관계·메타데이터에 반영하고 사용하는 에이전트에 폴더를 연결합니다.
3. 같은 질문 3개를 새 대화에서 실행하고 실제 답변·근거·모델명을 보관합니다.

## 완료 기준
내 에이전트 연결 데모, 실제 after 응답 JSON, 출처 확인 기록

## 동료 확인 질문
답변의 핵심 문장마다 내 원자료의 어느 부분이 근거인지 확인했나요?

## 기록과 공유
정상 답변과 실패 또는 판단 보류 장면을 함께 사례글에 넣습니다.

초등교육·건축 예시에서 관계를 읽는 방법을 확인한 뒤, 자기 주제의 대상과 근거로 바꿉니다. 예시 이름만 바꾸거나 참고 답변을 실제 성과로 제출하지 않습니다.
