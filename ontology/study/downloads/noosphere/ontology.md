# 누스피어 세계관 온톨로지

작성: 육대근 · DECK · 개정: 2026-10-06

작가가 실제 참고한 이론·문헌과 자신의 개념·작품 대응을 연결한 독립 학습 예제. 정본의 해석, 추가 해석 제안, 허구의 서사 설정을 구별합니다.

## 읽는 기준

정본에 기록된 연결은 작가 문서의 내용입니다. 이론의 원문 대조나 작품 효과 검증을 대신하지 않습니다. 해석 제안은 별도로 표시하며 서사 설정은 현실의 법칙과 구별합니다.

## 네 역학과 회복

감응 → 융해 → 결정 → 발산 → 잔향 → 회복의 조건 → 다음 감응. 회복은 다섯 번째 역학이 아닙니다.

## 질문으로 따라가기

### 혼돈의 호흡은 왜 융해인가?

혼돈의 호흡 → 융해 → 내-작용 → 바라드의 행위적 실재론

정본은 이질적인 데이터가 합류하는 혼돈의 호흡을 융해에, 융해를 내-작용에 연결합니다. 이는 작가의 이론적 해석이며 작품 효과의 과학적 검증은 아닙니다.

### 역치와 몸의 지각은 어떻게 연결될까?

Threshold #01 · 역치 → 감응 → 체화된 지각 → 메를로퐁티의 현상학

역치 기획은 감응의 문턱을 체험하도록 설계됐고, 감응은 몸을 통한 지각을 참조합니다. 기획의 이론적 위치를 보여주며 실제 전시 완료를 뜻하지 않습니다.

### 잔광에서 시간의 이론을 따라가면?

잔광 → 잔향 → 객체적 불멸성 → 화이트헤드의 과정 철학

잔광의 흔적을 잔향으로 읽고, 정본이 잔향에 대응시킨 객체적 불멸성에서 과정 철학으로 이어집니다. 시리즈 Afterglow와 작품 잔광은 별도 대상입니다.

### 회복은 왜 다섯 번째 역학이 아닐까?

회복 → 창조적 전진 → 화이트헤드의 과정 철학

2026-09-08 개정은 회복을 잔향에서 다음 감응으로 넘어가는 조건으로 정의합니다. 같은 자리의 반복이 아닌 다음 사건이라는 관점에서 창조적 전진을 참조합니다.
