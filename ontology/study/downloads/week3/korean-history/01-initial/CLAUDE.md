# Claude Code 작업 지침

이 폴더의 [AGENTS.md](AGENTS.md), [README.md](README.md), [state.json](state.json)을 먼저 읽는다. AKM 스킬이 설치되어 있으면 재개는 akm-maintain, 탐구는 akm-explore, 연결 보완은 akm-connect, 검수는 akm-lint/akm-review 역할을 사용한다. 미설치 환경에서도 파일은 독립적으로 읽고 검사할 수 있다.

가상 인터뷰를 실제 사용자 발언으로 오인하지 않는다. 새 작업 전 [재개 기록](operations/resume.md)을 확인하고 완료된 작업을 반복하지 않는다.
