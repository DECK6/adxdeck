# 이 독립 지식 공간에서 작업하기

먼저 README.md, domain-brief.md, state.json과 operations/resume.md를 읽는다. interview.md는 가상 사용자 역할극이며 실제 사용자의 기억이나 역사 근거로 승격하지 않는다.

- ontology.json이 의미 모델 정본이다. notes.json과 각 노트의 메타데이터에 같은 ID를 유지한다.
- 새 지식을 조사할 때 출처를 실제로 읽고 sources에 짧은 인용·위치·요약을 남긴다. 기존 출처 카드는 덮어쓰지 않는다.
- 새 주장만 추가하지 말고 관련 기존 설명과 링크, questions, state의 상태도 갱신한다.
- 원자료 역일을 양력으로 바꾸지 않으며, 연도 정밀도 자료에 월일을 채우지 않는다.
- CF1과 보류 질문을 없애서 완료로 만들지 않는다. 새로운 근거로 해결하거나 보류 상태를 설명한다.
- 지식 수정 뒤 리비전을 올리고 ontology.md와 knowledge-map.json을 갱신한다. 의미 검토를 실제로 다시 수행한 질문에만 현재 리비전의 checks를 기록한다.
- knowledge-map.json은 검사 투영본이다. 파일 해시 갱신만으로 의미 검토가 완료된 것으로 처리하지 않는다.
- 초기 스냅샷의 재현성을 보존하려면 새 작업은 별도 복사본에서 한다. 삭제 요청은 기본적으로 휴지통 이동이다.
