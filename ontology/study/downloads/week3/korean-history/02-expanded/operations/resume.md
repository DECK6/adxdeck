# 다음 세션에서 이어가기

[state.json](../state.json)의 cycle-01은 완료했다. Q5·Q6를 다시 새 질문으로 만들거나 N4·N5를 중복 생성하지 않는다. 최초 N1–N3의 ID와 인터뷰의 가상 표시를 유지한다.

현재 범위에서 자동 확장을 멈춘 이유는 3개 작업을 마쳤기 때문이다. 한국사 전체를 끝냈기 때문이 아니다. Q7은 사회집단·시기·지역을 좁히는 인터뷰가 필요하고 Q8은 국호 날짜 차이에 관한 추가 근거가 필요하다. 계속 확장하라는 요청을 받으면 state의 보류 이유를 읽고 해당 질문 범위를 정해 다시 조사한다. CF1을 없애서 검증을 통과시키지 않는다.

확장 순서: 질문 선택 → 원출처 읽기 → 기존 ID·중복 확인 → 필요한 주장과 노트 보강 → 기존 노트 연결 → 의미 검토 → map 갱신 → lint/coverage → 실행 기록과 다음 상태. 새 노트 수는 목표가 아니며 기존 설명을 보강하는 것만으로도 유효한 확장이다.

이 결과는 한 번의 실제 에이전트 실행으로 만들었다. 배경 예약 작업은 설정하지 않았다. 원본 출처 카드와 이번 리비전을 보존하려면 다음 작업은 새 복사본에서 수행한다.
