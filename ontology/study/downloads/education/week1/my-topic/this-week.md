# 1주차 · 내 주제와 자료로 출발

작은 테스트 20–30분 — 시간은 권장값입니다.

1. 최근 반복해서 찾는 업무·연구 주제를 한 문장으로 좁힙니다.
2. 내 자료 3–5개를 고르고 현재 상태·빠진 조건·조건 변경을 확인할 질문 세 개를 정합니다.
3. 정리 전 답변을 기록한 뒤 AKM에서 Wiki를 만들고 문서 링크를 확인합니다.

## 완료 기준
도메인 정의서, 작은 자료 묶음, 고정 질문 3개, before 응답, LLM Wiki v1

## 동료 확인 질문
아무 자료나 한 개 골랐을 때 출처와 연결 문서를 다시 찾을 수 있나요?

## 기록과 공유
무엇을 자주 찾았고 어떤 구조로 바꿨는지 사례글로 남깁니다.

요리·재료·보관함을 내 판단 대상·조건 또는 자원·확인된 상태로 대응시킵니다. 관계의 뜻과 판단 규칙을 내 업무에 맞춰 정의하고 예상 답·근거·보류 조건을 기록합니다. 예상 답은 실제 실행 결과와 구분합니다.
