# E09 · 경로 P1 · 분수 덧셈 준비

도달 목표는 분모가 같은 분수의 덧셈이다. 제안 경로는 똑같이 나누기 → 분수의 뜻 → 단위분수 → 같은 분모의 크기 비교 → 덧셈이다. 어려움이 발견되면 앞 단계의 설명을 다시 살핀다. 자동 학생 배치 규칙은 아니다.
