## 결론 — 단순 질문은 차이가 작고, 넓은 범위의 질문은 속도와 답변 품질 모두 차이가 크다

**이번 실험에서는 단순 질문의 차이는 작았지만, 범위가 넓은 복합·집계 질문에서는 온톨로지 적용본이 속도와 답변 품질 모두에서 뚜렷한 차이를 보였습니다.**

기본 실험과 [추가 대규모 실험](large-scale/REPORT.md)을 함께 보면 다음과 같습니다.

- **단순 조회:** 기본 실험의 호랑이 학명 조회(c01)는 양쪽 모두 3/3회 정답이었고, 시간 중앙값은 미적용 12.3초·적용 11.0초로 차이가 작았습니다.
- **넓은 범위의 답변 품질:** 추가 대규모 집계 6문항을 각 3회 실행했을 때, 미적용은 완전 정답 0/18회(18회 모두 답변 유보), 적용은 18/18회였습니다. 여기서 품질은 요구한 범위·총계·집계행 등을 정확하고 빠짐없이 제시하는 정확성과 완전성을 뜻합니다.
- **넓은 범위의 응답 속도:** 추가 실험의 시간 중앙값은 미적용 41.9초 → 적용 22.5초로 약 46% 줄었습니다. 미적용은 답변을 유보하기까지, 적용은 완전 정답을 제시하기까지 걸린 시간입니다.

즉, 자료 한 건을 찾을 때보다 여러 분류 관계를 따라 범위를 정하고, 조건에 맞춰 제외·집계해야 할 때 적용본의 효과가 두드러졌습니다. 같은 모델과 최대 8회 조회 예산에서 명시적 분류 관계와 DB 집계 도구를 함께 제공한 시스템 비교이며, 온톨로지 단독의 인과 효과를 분리해 측정한 결과는 아닙니다.

## 측정 범위

첫 실행 시작부터 마지막 실행 종료까지 851.25초(14.19분). 같은 질문의 두 버전을 동시에 실행했으므로 전체 경과 시간은 개별 시간의 합이 아닙니다. CLI 시작·추론·조회·네트워크 대기·종료를 포함합니다.

사용량은 Codex turn.completed의 실제 토큰입니다. 내부 지침과 반복 문맥도 포함하며 캐시·추론 토큰을 별도 보존했습니다. **구독 한도를 사용했으며 API 요금이나 건당 청구액으로 환산하지 않습니다.** 공개 runs/에는 답변·도구 조회·사용량·채점 기록이 있습니다. 실행 명령·세션 ID·CLI 이벤트는 로컬 원본에 보관하며 공개 사본에서 제외했습니다.

동일 원본 62,604항목, 조회 최대8회·16항목/회, 도구 출력 최대20,000토큰, 질문당300초 제한, 재시도0회입니다. 미적용본도 전체 일치 수·논리 검색·페이지 조회를 사용할 수 있습니다. 공통 분류군과 집계 계급은 별도 필드로 응답합니다.

이 결과는 명시적 관계와 DB 집계 도구를 추가한 시스템 비교입니다. 온톨로지 단독 인과 효과나 SQL 대비 우월성을 의미하지 않습니다. c04는 제외 후256항목으로 원문 전수 열람에는16페이지가 필요하므로 조회8회 예산과 집계 도구 차이가 결과에 영향을 줍니다. 8문항3회 반복의 수업용 표본입니다.
