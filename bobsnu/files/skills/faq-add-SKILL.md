# FAQ 추가

"확인 필요"로 넘겼던 질문에 담당자 답이 왔을 때 쓴다. 이렇게 넣어 두면 같은 질문은 다음부터 에이전트가 답한다.

## 받을 것
- 고객 질문 원문
- 담당자가 확인한 답과 그 근거
- 승인한 사람과 날짜. 없으면 넣지 말고 묻는다.

## 순서
1. `예시` 파일의 FAQ 모음에서 비슷한 질문을 찾는다.
   - 같은 질문이 있고 답이 같다 → 넣지 않는다.
   - 같은 질문이 있는데 답이 다르다 → 새로 만들지 말고 기존 항목을 고칠 것을 제안한다. 옛 답과 새 답을 나란히 보여 준다.
   - 없다 → 새 항목을 만든다.
2. 제목은 고객이 실제로 쓰는 말로 쓴다. "배송비 정책안내"가 아니라 "얼마 이상 사면 무료배송인가요?".
3. 첫 문장에 답을 쓴다. 조건과 예외는 그다음에 쓴다.
4. 적용 범위를 적는다: 어느 제품, 어느 판매처, 언제부터.
5. 다시 볼 날짜를 적는다. 행사·가격·배송 조건은 바뀌기 쉬우므로 기한을 붙인다.

## 출력
```
질문:
답: (첫 문장에 답)
조건·예외:
적용 범위:
근거:
승인: (이름, 날짜)
기준일:
다시 볼 날:
```
그 아래에: 기존 FAQ와 겹치는 항목, 목록표에 넣을 한 줄.

## 하지 않는 것
- 승인자가 없는 답을 FAQ로 만들지 않는다.
- 담당자의 답을 더 그럴듯하게 고쳐 쓰지 않는다. 뜻이 바뀐다.
- 한 번만 있었던 특수한 사례(특정 고객의 예외 처리)를 FAQ로 만들지 않는다.
- 고객 이름, 주문번호, 연락처를 넣지 않는다.

## 끝내기 전 확인
- 답의 첫 문장만 읽어도 질문이 풀리는가.
- 승인자와 기준일이 있는가.
