# 월간 보고 초안

검산표를 받아 보고 초안을 쓴다. 검산이 안 된 표로는 쓰지 않는다. 먼저 monthly-check를 하라고 안내한다.

## 순서
1. 검산표에서 "표시한 곳"이 남아 있는지 본다. 남아 있으면 보고서 맨 위에 적는다.
2. 증감을 금액이 큰 순서로 늘어놓는다. 기준의 변동 폭을 넘는 것만 설명 대상으로 삼는다.
3. 항목별 증감을 더한 값이 전체 증감과 같은지 확인한다(다리표).
4. 증감마다 세 가지를 적는다: 얼마나 변했나(금액과 비율), 왜(자료에 적힌 원인만), 다음에 할 일.
5. 원인이 자료에 없으면 "원인 미확인, 담당자 확인 필요"라고 적는다.
6. `예시` 파일의 지난 보고서 형식을 따른다. 없으면 아래 형식을 쓴다.

## 출력
```
[월간 보고 초안] 2026년 ○월 (단위: 천원)

1. 한 줄 요약
2. 확인이 끝나지 않은 숫자 (있으면)
3. 매출 합계와 전월 대비
4. 채널별 증감 (큰 순서)
   - 채널 / 증감액 / 증감률 / 원인 / 다음 할 일
5. 다리표: 지난달 합계 → 항목별 증감 → 이번 달 합계
6. 담당자가 채울 것
```

## 하지 않는 것
- 숫자만 다시 읽는 문장을 쓰지 않는다. "홈쇼핑이 증가했다"가 아니라 얼마, 왜, 그래서 무엇을.
- 원인을 추측해 쓰지 않는다. "계절 요인으로 보인다" 같은 문장은 자료에 근거가 있을 때만 쓴다.
- 확인이 끝나지 않은 숫자를 본문 결론에 쓰지 않는다.

## 끝내기 전 확인
- 보고 문장의 숫자가 검산표와 같은가.
- 다리표의 합이 맞는가.
- 모든 숫자는 사람 승인 대상이라고 적었는가.
