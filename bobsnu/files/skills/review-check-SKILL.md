# 결과물 검수

초안의 문장을 원자료와 대조해 판정표를 만든다. 초안을 고쳐 쓰는 스킬이 아니다. 판정만 하고, 고치는 일은 사람이 정한다.

## 받을 것
- 검수 대상 초안
- 원자료 (지식 파일 또는 첨부). 원자료가 없으면 시작하지 말고 요청한다.

## 순서
1. 초안을 **하나만 확인하면 되는 문장**으로 쪼갠다. "당류가 1g이라 혈당 관리에 도움이 됩니다"는 "당류 1g"과 "혈당 관리에 도움" 두 개다.
2. 문장마다 원자료에서 근거 위치(파일 이름, 항목 또는 쪽)를 찾는다.
3. 숫자와 단위, 날짜, 조건어(이상/미만, 접수/확인, 일/영업일, 주문분/출고분)를 원문과 글자 그대로 비교한다. 계산이 있으면 직접 다시 계산한다.
4. 원자료끼리 내용이 다르면 양쪽을 적고 각 자료의 기준일을 붙인다. 어느 쪽이 맞는지 정하지 않는다.
5. 아래 표로 낸다.

## 판정
| 상태 | 뜻 |
|---|---|
| 확인 | 원자료에 같은 내용이 있고 숫자·조건이 일치한다 |
| 수정 필요 | 원자료에 내용이 있는데 초안과 다르다 |
| 확인 필요 | 원자료에 없다. 틀렸다는 뜻이 아니라 근거가 없다는 뜻이다 |

## 출력
| # | 초안 문장 | 원자료 위치와 기준일 | 상태 | 이유 | 사람 승인 |
|---|---|---|---|---|---|

표 아래에 세 줄을 붙인다: 상태별 개수, 원자료끼리 다른 곳, 사람 승인이 필요한 줄.

## 사람 승인으로 표시할 것
효능·건강·질환 관련 표현, 가격·납기·할인·독점 조건, 보고서에 들어가는 최종 숫자, 연구 결과를 해석한 문장.

## 하지 않는 것
- 원자료에 없는 내용을 일반 지식으로 "확인" 처리하지 않는다.
- 초안을 다시 써 주지 않는다. 요청받으면 수정 제안을 한 줄로만 붙인다.
- "대체로 맞음" 같은 중간 판정을 만들지 않는다.

## 예시
초안: "3만 5천원 주문은 2만원 이상이므로 무료배송입니다."
원자료: 구 FAQ(2020-07-03) "2만원 이상 무료", 현행 FAQ(2026-11-26 조회) "40,000원 미만 3,000원"

| # | 초안 문장 | 원자료 위치와 기준일 | 상태 | 이유 | 사람 승인 |
|---|---|---|---|---|---|
| 1 | 3만 5천원 주문은 무료배송 | 현행 FAQ 배송비 (2026-11-26) / 구 FAQ (2020-07-03) | 수정 필요 | 옛 기준을 따랐다. 현행은 40,000원 미만 3,000원 | |

## 끝내기 전 확인
- 모든 줄에 원자료 위치가 있거나 "확인 필요"인가.
- 계산을 직접 다시 했는가.
