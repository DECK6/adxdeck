# 지식베이스 연결 (어댑터)
<!-- 이 블록을 지침 파일(CLAUDE.md)의 맨 위에 붙입니다. 괄호 부분만 내 것으로 바꿉니다. -->
지식베이스 위치: (bobsnu-kb/분야 이름)  (공통: bobsnu-kb/common)

## 먼저 읽는다
1. common/CLAUDE.md   회사 공통 지침
2. (분야)/index.md    무엇이 어디에 있는지
3. (분야)/terms.md    용어와 기준

## 찾는 순서
index.md → knowledge의 정리 문서 → sources의 원자료
숫자·날짜·조건은 원자료를 열어 대조한 뒤 쓴다.
status가 "대체됨"인 문서는 쓰지 않는다.

## 없을 때
답을 만들지 않는다. "확인 필요"로 적고 정리 문서의 owner를 넘길 사람으로 적는다.

## 고치는 범위
raw와 sources는 읽기만 한다.
knowledge와 terms.md는 고치지 말고 고칠 내용을 제안한다.
틀린 답을 찾으면 fix-log.md에 한 줄을 더한다.
결과물은 내 폴더의 outputs에 저장한다.
