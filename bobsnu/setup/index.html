Claude 데스크탑 앱과 실습 폴더

오늘 실습은 브라우저가 아니라 데스크탑 앱에서 합니다. 앱이 내 컴퓨터의 실습 폴더를 직접 읽고 고칩니다.

1 · 앱 설치와 로그인

  1. claude.com/download에서 내 컴퓨터에 맞는 설치 파일을 받습니다. macOS 13 이상, Windows 10 이상에서 됩니다.
  2. 설치 파일을 실행합니다. Windows에서 "이 앱이 디바이스를 변경하도록 허용하시겠습니까?"가 뜨면 허용합니다.
  3. 앱을 열어 본인 계정으로 로그인합니다.
Windows 회사 PC는 관리자 권한으로 설치해야 폴더 연결 기능을 쓸 수 있습니다. 권한이 없으면 전산 담당자에게 미리 설치를 요청해 주세요. 폴더 연결은 유료 요금제(Pro, Max, Team, Enterprise) 계정에서 됩니다.

3 · 폴더 연결

  1. 앱에서 새 대화를 엽니다.
  2. 입력창에서 폴더를 고르는 버튼을 누릅니다. 이름은 Work in a folder입니다. 입력창에 Cowork 선택지가 따로 보이면 그것을 먼저 고릅니다.
  3. bobsnu-agent 폴더를 고릅니다. 접근을 묻는 창이 뜨면 폴더 경로가 맞는지 읽고 승인합니다.
  4. 아래 문장을 보내 파일 목록이 나오는지 확인합니다.
이 폴더에 어떤 파일이 있는지 목록으로 알려 줘. 아직 아무것도 고치지 마.

앱 버전에 따라 버튼의 이름과 위치가 조금 다를 수 있습니다. 한 번 허용한 폴더는 Settings → Trusted folders에서 볼 수 있습니다.

4 · 지침 넣기 (모듈 02에서 합니다)

  1. 폴더의 CLAUDE.md를 메모장으로 열어 내 규칙 3개를 넣고 저장합니다.
  2. 앱의 Customize → Folder instructions에 같은 내용을 붙여 넣습니다.
  3. 이 메뉴가 보이지 않으면, 요청할 때 첫 줄에 아래 문장을 적습니다.
먼저 CLAUDE.md를 읽고 그 규칙대로 해 줘.

지킬 것

하는 것하지 않는 것
받은 실습 폴더 하나만 연결합니다.바탕화면, 문서 폴더, 공유 드라이브 전체를 연결하지 않습니다.
연결할 때 뜨는 폴더 경로를 읽고 승인합니다.사내 문서, 고객 정보, 공개 전 제품·가격 정보를 폴더에 넣지 않습니다.
파일을 지워도 되는지 물으면 읽고 나서 누릅니다.시키지 않은 일을 하려 할 때 그대로 두지 않습니다. 멈춥니다.
폴더를 연결하면 Claude가 그 안의 파일을 읽고, 고치고, 새로 만들 수 있습니다. 연결한 파일의 내용은 답을 만들기 위해 Anthropic 서버로 전송됩니다.
